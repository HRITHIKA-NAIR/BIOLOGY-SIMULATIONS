About this teaching model and sources

This first prototype uses a simplified, saturating light-response model, not measured experimental data. Repeated runs at the same distance give identical counts in this first version; real trials vary. Distances of 10–50 cm, a 30-second simulated adjustment and 60-second measurement are prototype settings, not verified timings from the video. Carbon dioxide availability and temperature stay constant. The 1/d² light index is an idealised approximation, not a calibrated light reading.

The model demonstrates a trend; real measurements vary with species, lamp, ambient light and other limiting factors. The result counter counts each bubble emitted by the animation. Existing trials remain when you move between instruction steps; restarting a trial clears only the current run.

Sources: AQA practical assessment · Your reference video. The video's full method has not yet been verified.
